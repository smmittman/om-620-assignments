# OM 620: Supply Chain Analytics Assignments

## Overview
This repository contains data and Jupyter notebooks for OM 620, focusing on data preparation, exploratory data analysis, and supply chain performance visualization.

## Repository Structure
- **`data/`**: Metadata and raw transaction datasets.
- **`notebooks/`**: Combined Jupyter notebook for Assignments 1 and 2.

## Accomplishments & Findings (Assignments 1 & 2)
- Merged transaction and metadata tables, cleaned missing values, and formatted date fields for time-series analysis.
- Analyzed delivery delays, invoice amounts, and performance trends across manufacturing sites and transportation modes.
